CozyPet 3.0 — Cozy World
==========================
File:
- index.html
- style.css
- script.js
- favicon.svg

Cara upload GitHub Pages:
1. Buat repository baru di GitHub.
2. Upload semua file ini ke root repository.
3. Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Save.
7. Tunggu proses deployment selesai.

Game menyimpan progress dengan localStorage browser.
Tidak membutuhkan database, server, atau backend.

Fitur 3.0:
- Virtual pet + status
- EXP, level, coins, gems
- Home, Garden, Cozy Cafe, Town Shop, Fun Park
- Garden planting/harvesting
- Food shop

- Decor
- Mini games
- Daily reward + streak
- Day/night indicator
- Weather mood

- Responsive mobile/desktop
