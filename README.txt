CozyPet 1.0
=============
File utama:
- index.html
- style.css
- script.js
- favicon.svg

Cara deploy GitHub Pages:
1. Buat repository baru.
2. Upload keempat file tersebut ke root repository.
3. Pastikan index.html berada langsung di root.
4. Settings > Pages > Deploy from branch > pilih main / root.
5. Buka URL GitHub Pages.

Game memakai localStorage, jadi progress tersimpan di browser yang digunakan.
